# Состав и проверка

В архиве 60 включённых модов профиля и Simplicity of Snow, который был выключен в Vortex, но развёрнут в Data.
Skyrim SE 1.7.104.0, SKSE 2.3.1, Skyrim Together Reborn 1.8.4. SKSE, Skyrim Together и Address Library внутри.
44 активных плагина, включая 10 официальных плагинов из Steam. Для активных плагинов в исходном снимке отсутствующих мастеров не найдено.
Для 0 отсутствующих путей взяты файлы из staging. 49 записей относятся к текстурам Skyrim 202X, отсутствовавшим и в Data, и в папке исходного мода. Эти пути пропущены. Для 0 путей сохранена версия из Data.
Nordic Snow помещён в Mods целиком. Список развёртывания содержит используемых победителей конфликтов, поэтому при установке воспроизводится их порядок.
Русские ресурсы и активные версии модовых плагинов включены. Официальные игровые файлы, включая русские файлы официальных дополнений, предоставляет Steam. Резервная копия Alternate Start с датой в имени вне рабочего порядка загрузки.
Успешность кооператива на отдельной установке не проверялась. Совместимость конкретной сборки Engine Fixes с Skyrim 1.7.104 требует проверки. Архив проверяется после упаковки, результат хранится рядом с 7z.
