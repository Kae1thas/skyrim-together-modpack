# Skyrim Together Modpack

Сборка для Steam-версии Skyrim Special Edition 1.7.104.0. В комплекте 60 включённых модов, развёрнутый Simplicity of Snow, SKSE 2.3.1, Skyrim Together Reborn 1.8.4, настройки и порядок загрузки.

## Установка

1. Скачайте из Releases все четыре части Skyrim_Together_Full.7z.001–004 в одну папку.
2. Откройте Skyrim_Together_Full.7z.001 в 7-Zip и распакуйте сборку.
3. Следуйте README_RU.md из архива. Установщик Install.ps1 использует уже установленную Steam-версию игры.

Игровые файлы предоставляются Steam. Установка на отдельном ПК и кооператив не тестировались. В исходной установке отсутствовали 49 текстур Skyrim 202X, перечисленных в отчёте внутри архива.
